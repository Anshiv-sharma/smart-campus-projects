# Smart Campus & Student Life: 10 mini projects

Static front-end apps, one per folder. Each folder is its own Vercel project.

- `bunk-meter`: Know how many classes you can skip, or must attend, to stay above the attendance cut-off.
- `mess-menu`: Today's hostel mess menu, without walking down to read the notice board.
- `free-room-finder`: Find an empty classroom to study in during any slot.
- `lost-and-found`: One shared board for lost and found items around campus.
- `study-buddy`: Pick a subject and see classmates who want to study it too.
- `shuttle-tracker`: See when the next campus shuttle leaves.
- `exam-countdown`: Add your exams and see how many days you have left.
- `canteen-queue`: Check which canteen is crowded before you go.
- `event-hub`: Every club event in one place. RSVP in a tap.
- `hostel-split`: Split a shared bill between roommates in seconds.
